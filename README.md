# justExpress

A collection of Express.js learning examples and small practice projects. Each project folder is intended to be explored independently; examples include introductory Express apps, EJS, file uploads, authentication, APIs, and React integration.

## Getting started

1. Choose a project folder.
2. Read that folder's files and any local notes before running it.
3. If it contains a `package.json`, install and run its scripts from that folder:

   ```sh
   npm install
   npm run
   ```

   `npm run` lists the commands available for that example. Different folders may use different dependencies and ports.

The root is a collection rather than a single application, so there is no root-level install or start command. Treat the examples as learning material and review their dependencies and configuration before exposing any server publicly.
